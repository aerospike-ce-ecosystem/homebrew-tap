# homebrew-tap

Homebrew tap for [aerospike-ce-ecosystem](https://github.com/aerospike-ce-ecosystem) tools.

## Available formulae

| Tool | Install |
|------|---------|
| [ackoctl](https://github.com/aerospike-ce-ecosystem/ackoctl) | `brew install aerospike-ce-ecosystem/tap/ackoctl` |

## Adding the tap

```bash
brew tap aerospike-ce-ecosystem/tap
```

Formulae in this tap are bumped automatically by goreleaser whenever a new
release is tagged in the source repository — do not edit `Formula/*.rb` by
hand.
